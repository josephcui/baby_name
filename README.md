# 宝宝起名向导 · 智能取名

一个纯前端的中文宝宝起名网站。无需后端、无需构建，直接用浏览器打开 `index.html` 即可使用。

结合 **字义寓意 · 五行调和 · 声调韵律 · 古籍出处**，为宝宝生成有文化底蕴的好名字，并解释每个名字「为什么好」。

## 功能特性

- **多维度输入**：姓氏、性别（男孩/女孩/不限）、名字字数（单字/双字）、五行偏好、期望寓意（11 种标签多选）、避免用字。
- **智能打分算法**：综合寓意匹配、五行相生、声调起伏、性别贴合等维度为候选名字打分排序，并在接近最高分的优质候选中随机抽取，保证质量的同时每次都有新鲜感。
- **可解释的推荐**：每个名字都会展示推荐理由、逐字释义、带声调拼音、五行属性与诗词典籍出处。
- **收藏与复制**：一键收藏心仪的名字（本地保存，刷新不丢失），一键复制名字。
- **精美响应式 UI**：玻璃拟态卡片、柔和暖色渐变、细腻动效，适配手机与电脑。

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构与表单 |
| `style.css` | 视觉样式（配色、卡片、动效、响应式） |
| `data.js` | 起名字库（汉字 + 拼音 + 释义 + 五行 + 性别倾向 + 寓意标签 + 出处） |
| `script.js` | 起名打分算法与交互逻辑（收藏、复制、渲染） |

## 本地使用

直接双击 `index.html`，或启动一个静态服务器：

```bash
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 算法说明

候选名字会从字库中生成所有合法组合，并按以下维度加权打分：

1. **寓意匹配**：命中用户期望标签越多，得分越高。
2. **五行**：含目标五行的字加分；双字之间若构成「相生」（木生火、火生土、土生金、金生水、水生木）额外加分。
3. **声调搭配**：两字声调不同、与姓氏声调错落，读起来抑扬顿挫。
4. **性别贴合**：精确匹配性别倾向的字略微加分。

> 名字仅作创意参考。传统五行/生肖等说法属于文化习俗，请结合家庭喜好理性看待。

## 扩展字库

在 `data.js` 的 `CHAR_LIBRARY` 中按相同字段新增汉字即可，算法会自动纳入候选。
